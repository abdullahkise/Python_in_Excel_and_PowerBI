4. DAX Cheat-Sheet

Net Satış        = SUM(FactSales[NetAmount])
Kâr Marjı %      = DIVIDE([Brüt Kâr], [Net Satış])               -- oran: DIVIDE
Sipariş Sayısı   = DISTINCTCOUNT(FactSales[OrderID])
Bisiklet Net     = CALCULATE([Net Satış], DimProduct[Category] = "Bisiklet")
Pay % (Toplam)   = DIVIDE([Net Satış], CALCULATE([Net Satış], ALL(DimProduct)))
Pay % (Görünür)  = DIVIDE([Net Satış], CALCULATE([Net Satış], ALLSELECTED(DimProduct)))
Pay % (Kat. içi) = DIVIDE([Net Satış], CALCULATE([Net Satış], ALLEXCEPT(DimProduct, DimProduct[Category])))
Net YTD          = TOTALYTD([Net Satış], DimDate[FullDate])
Net LY           = CALCULATE([Net Satış], SAMEPERIODLASTYEAR(DimDate[FullDate]))
YoY %            = DIVIDE([Net Satış] - [Net Satış LY], [Net Satış LY])
Ay Başına Net    = DIVIDE([Net Satış], COUNTROWS(FILTER(VALUES(DimDate[YearMonth]), [Net Satış] > 0)))

Yerleşik CORREL DAX fonksiyonu yoktur. Hızlı ölçü > Korelasyon katsayısı ya da SUMX tabanlı Pearson.

Soru Fonksiyon
Filtreyi tamamen kaldır ALL / REMOVEFILTERS
Seçili (dilimleyici) içindeki pay ALLSELECTED
Bir kolon dışındakileri kaldır ALLEXCEPT
Yıl başından bugüne / çeyrek / ay DATESYTD (TOTALYTD) / DATESQTD / DATESMTD
Geçen yılın aynı dönemi SAMEPERIODLASTYEAR
Hareketli 3 ay DATESINPERIOD

6. Hatırlanacaklar

  1. Oranı toplama, her bağlamda yeniden böl.
  2. Tarih tablosunu işaretle; yoksa Time Intelligence yanlış/boş.
  3. Toplam ≠ ay başına; doğru paydayı seç.
  4. Korelasyon ≠ nedensellik; türev değişkenleri (net ↔ kâr) karşılaştırma.
  5. Power BI regresyon hesaplamaz; hesapla, getir, sun.
  6. Python görseli = resim, 150.000 satır sınırı, Service'te paket kısıtı.
  7. Yayın = yenileme (gateway) + yetki (RLS/App) + sahiplik.
